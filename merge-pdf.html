How to merge PDF files

  1. Open Free PDF Toolkit and select the Merge tab.
  2. Click Add files and choose your PDFs. The order you add them is the order of the final document.
  3. Optionally set a name for the merged file with Browse.
  4. Press Merge. A single PDF containing all pages is created.

Common uses

  • Combine scanned pages into one contract or invoice.
  • Attach receipts and attachments into a single expense report.
  • Put a cover letter and CV into one application PDF.
  • Join chapters from different sources into one ebook.

Need the opposite? Use Split PDF, or compress the result to make it smaller.

Is there a limit on how many PDFs I can merge?

No. Add as many files as you need.

Will the quality change?

No. Pages are copied as-is — no re-encoding, no quality loss.

Can I reorder files after adding them?

Remove and re-add them in the desired order, or rename your files so they sort correctly before selecting.
