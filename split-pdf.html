Two ways to split a PDF

  1. Open Free PDF Toolkit and select the Split tab. Add one PDF.
  2. Choose Every page → its own PDF and pick an output folder to get one file per page.
  3. Or choose Page range → one PDF, type the from/to pages and press Split.
  4. Your new PDFs appear in the chosen folder (or next to the original), named with the page number.

When is this useful?

  • Send only the relevant pages of a contract instead of the whole document.
  • Separate a scanned book into individual chapters.
  • Extract a single page to use as an image or attachment.
  • Reduce a huge PDF by keeping only the pages you need — then compress it.
Can I extract non-consecutive pages?

Use the page-range mode for a continuous block, or split all pages and keep the ones you want.

Are bookmarks and links preserved?

Page content is preserved exactly. Interactive links are not carried over.

Is there a page limit?

No. You can split documents of any length.
